## Antennarr v1.2.0-alpha.2

This GitHub prerelease is for Linux ARM64. It fixes channel names in Jellyfin, protects working portal lineups during refresh, and improves programme guide decisions when sources disagree. The recommended stable download is [v1.1.0](https://github.com/fxPPC/Antennarr/releases/tag/v1.1.0).

### Changes since alpha 1

- **Jellyfin** preserves channel names such as `5 USA` and `News, London`. Channel IDs and playback URLs stay stable across renumbering. The DVR test books a programme, renames and renumbers its channel, refreshes Jellyfin, and checks that the original timer records through a source failure. [#97](https://github.com/fxPPC/Antennarr/pull/97)
- **Programme guides** count each independent source once. A provider whose own streams disagree abstains. Two independent sources must agree to replace a known episode ID. Pinning a different station clears the old station’s listings, and late listings from a previous station no longer overwrite a correction. Small differences in feed times no longer hide the following programme when sources agree it airs. UK XMLTV feeds using BST and GMT distinguish the two 01:30 broadcasts when clocks go back. [#100](https://github.com/fxPPC/Antennarr/pull/100)
- **Portal refresh** keeps the last working lineup if a playlist ends halfway through a channel entry. If validation finishes after a station is withdrawn, the station stays out of the roster until the provider restores it. Renewing a subscription respects manual blocks and stream retirement settings. Identical duplicate entries retain their channel, and a provider reassigning a numeric station ID can no longer send an existing roster to the replacement station. [#98](https://github.com/fxPPC/Antennarr/pull/98)
- **Tuner navigation** retries failed requests, hides the previous tuner’s controls during a switch, and discards late responses. The setup wizard also recovers when a temporary error interrupts a return to the Status page. Plex and Jellyfin links open the selected tuner’s connection panel. [#99](https://github.com/fxPPC/Antennarr/pull/99)
- **Pull-request checks** run the Go race suite and desktop and phone browser tests on native Linux ARM64. Tuner and DVR fixture changes also exercise a real Jellyfin server with generated media and a simultaneous Plex-compatible viewer. [#96](https://github.com/fxPPC/Antennarr/pull/96)

### Run alpha 2 alongside another installation

Download `antennarr-v1.2.0-alpha.2-linux-arm64.docker.tar.gz` and `SHA256SUMS` from this release into the same directory. Verify the archive and load its versioned image.

```sh
sha256sum --check --ignore-missing SHA256SUMS &&
  docker load -i antennarr-v1.2.0-alpha.2-linux-arm64.docker.tar.gz
```

The example uses a separate data volume and seven consecutive ports. Set `lan_ip` to the server’s private LAN address and choose a free range if 41200–41206 are occupied.

```sh
lan_ip=192.168.1.50
docker run -d --name antennarr-alpha2 \
  -p "${lan_ip}:41200-41206:41200-41206" \
  -e ANTENNARR_PORT_RANGE=41200-41206 \
  -e "ANTENNARR_BASE_URL=http://${lan_ip}" \
  -v antennarr-alpha2-data:/data \
  antennarr:v1.2.0-alpha.2
```

Open `http://<server-LAN-IP>:41200`. A fresh installation starts with username `admin` and password `admin`. Change the login and select a city in setup.

### Upgrade or roll back

For an existing alpha 1 or 1.1.0 installation, download a full backup from **Admin → Backup & restore** on that installation. Keep the backup private because it contains account credentials. Restore the archive into the separate alpha 2 instance while playback is idle. The restore restarts the service and brings over the saved login, channels, rosters, and tuner identities. Alpha 1 and alpha 2 use catalogue schema 10. Restoring 1.1.0 data into alpha 2 upgrades it from schema 9.

If replacing a tuner already configured in a DVR, stop the original instance and give alpha 2 its original advertised address and port range. For rollback, stop alpha 2 and restart the previous image with its original volume and ports, or restore the backup taken by that version.

### Connect clients and sources

In setup or **Tuners**, **Connect to Plex** shows the HDHomeRun tuner address and guide location. **Connect to Jellyfin** provides two URLs. Add the M3U tuner and XMLTV guide under **Dashboard → Live TV**, then refresh the guide. Each tuner has its own URLs and channel mapping. Its web view shows current and upcoming programmes, guide coverage, and standby streams.

For a MAC-based portal, enter the HTTPS portal URL and registered MAC under **Sources**. The provider must supply an authorised subscriber playlist export or supported subscriber-scoped Ministra REST access with playlist export enabled. An operator-provided XMLTV feed can supply guide listings.

# Antennarr

Antennarr imports authorised Xtream account lists, tests feeds, and serves Plex Live TV & DVR through an HDHomeRun-compatible tuner. Plex handles guides and recordings. Supply your own sources.

| Tag | Platforms | Installation |
| --- | --- | --- |
| `latest`, `1.0`, `v1.0.9` | Linux amd64 and ARM64 | Stable. One US tuner with 150 editable channels |
| `testing` (newest preview), `v1.1.0-beta.2` (pinned) | Linux amd64 and ARM64 | Public beta with 16 optional city presets |

Follow the [stable installation guide](https://github.com/fxPPC/Antennarr/blob/release/1.0/docs/INSTALL.md) or the [beta setup guide](https://github.com/fxPPC/Antennarr/blob/main/docs/MULTI-TUNER.md). Keep tuner ports private, change the initial admin login, and use a separate data directory for the beta. Back up before opening stable data in 1.1.

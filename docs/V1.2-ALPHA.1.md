## Try the Linux ARM64 alpha

This GitHub prerelease adds Jellyfin Live TV, programme guide consensus, subscriber portal sources, and a redesigned channel view. The stable release and the standard installation guides point to [v1.1.0](https://github.com/fxPPC/Antennarr/releases/tag/v1.1.0).

Download the Linux ARM64 Docker archive and SHA256SUMS from this release. In the download directory, run:

```sh
sha256sum --check --ignore-missing SHA256SUMS
docker load -i antennarr-v1.2.0-alpha.1-linux-arm64.docker.tar.gz
```

To try it alongside stable, choose a free port range, replace YOUR_SERVER_LAN_IP with your server’s private LAN address, and give the alpha its own data volume:

```sh
docker run -d --name antennarr-alpha \
  -p YOUR_SERVER_LAN_IP:41100-41106:41100-41106 \
  -e ANTENNARR_PORT_RANGE=41100-41106 \
  -e ANTENNARR_BASE_URL=http://YOUR_SERVER_LAN_IP \
  -v antennarr-alpha-data:/data antennarr:v1.2.0-alpha.1
```

Open the server on port 41100, sign in with the initial admin/admin login, and change it. If testing with existing settings, make a full backup in 1.1.0 first and restore it into a separate alpha instance. The alpha upgrades the catalogue to schema 10. To return to 1.1.0, use the original 1.1 appdata or restore its pre-alpha backup.

## Connect a tuner

Choose a city in the setup wizard. **Connect to Plex** shows its HDHomeRun address and guide location. **Connect to Jellyfin** provides the URL for an M3U tuner and the URL for an XMLTV guide. Both options are also available under Tuners. In Jellyfin, add both URLs under Dashboard → Live TV, refresh the guide, and schedule a recording. Each enabled tuner serves its own channels. The channel's playlist ID and playback path survive roster turnover, renaming, and renumbering.

## Programme guides

Antennarr uses guide IDs from roster streams and can import an external XMLTV feed per tuner. It groups matching programmes by provider host or the source named in the XMLTV feed. Unlabelled mirrors on separate hosts can appear independent. Multiple accounts at one provider contribute one vote. A single guide can supply an empty slot. A corroborated majority can correct an existing listing. During provider disagreement or an outage, existing listings remain available through their scheduled end. Local station and timeshift matching help distinguish regional broadcasts.

Open a tuner to see working feeds, standby status, current and upcoming programmes, and guide coverage. Select a channel to compare candidate listings or pin a guide station. Return to automatic selection to resume voting.

## Portal accounts

In Sources, select the portal option and enter the HTTPS portal URL and its registered MAC. Use the subscriber’s operator-issued playlist export or supported subscriber-scoped Ministra REST access with playlist export enabled. An operator-provided XMLTV guide can supply listings. Support depends on the interfaces enabled by the provider. Device-only portals that require a physical set-top box are outside this release’s compatibility claim.

## Verification

The release assets include the native Linux ARM64 Docker archive, build revision, SHA-256 checksums, software bill of materials, vulnerability scan, and Jellyfin recording report. The recording test uses generated media and a real Jellyfin server. Plex coverage exercises the HDHomeRun interface and simultaneous access through the two client paths. It does not certify every combination of Plex server and viewing device.

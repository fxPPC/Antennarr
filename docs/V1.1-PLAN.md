# Stable 1.1.0 acceptance

1.1.0 is in preparation. The latest public 1.1 build is [beta 2](https://github.com/fxPPC/Antennarr/releases/tag/v1.1.0-beta.2). See the [multi-tuner setup guide](MULTI-TUNER.md) for supported presets, ports, and data migration.

## Upgrade and rollback

Automated upgrade and restore checks use data created by the 1.0.0, 1.0.4, and 1.0.9 releases. They check device identities, saved settings, rosters, and edited channels. A separate rehearsal built each release from 1.0.0 through 1.0.9 and tested both direct migration and restoration of a backup made by that version. All 20 cases preserved the synthetic lineup, account and roster counts, and Plex identity.

Remaining upgrade checks:

- Exercise interrupted migrations, missing optional metadata, and backups near the supported size limit. An unsupported format must leave the original data intact.
- Exercise multi-tuner backup and restore during normal service activity.
- Establish the stable 1.1 fixture and historical-binary tests for same-minor patch downgrades. Cover settings saves, channel edits, cleanup, restore, and re-upgrade. [Compatibility policy](VERSIONING.md) · [Upgrade test commands](TESTING.md)

## Plex acceptance

Record the Plex server and client versions used. Check each of these on real devices:

- Register two independent tuners, select local guides, and schedule simultaneous recordings with overlapping channel numbers.
- Verify device identities, addresses, guide mappings, and channel edits after upgrade, restart, rename, and disable/re-enable.
- Check that failover keeps the correct regional service and measure the time until the client resumes playback.
- Exercise shared capacity limits with live viewers and recordings. Verify private-network tuner access and the primary stream-only fallback.

Publish stable 1.1.0 after these checks pass and publication is approved.

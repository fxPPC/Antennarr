TCP port range
Administration
Plex tuners

To change ports, choose seven consecutive TCP ports. The first serves administration and the next six serve Plex tuners.

  • In Docker, set ANTENNARR_PORT_RANGE and update the port mappings before recreating the container.
  • On Windows, run Setup again to change the range and update the optional private-network firewall rule.
  • On macOS, quit Antennarr, save the range in config/port-range in its data folder, and reopen it. For example, enter 40000-40006.

An explicit ANTENNARR_PORT_RANGE takes precedence over the saved range. After a change, use the new administration port and update the affected tuner addresses in Plex.
